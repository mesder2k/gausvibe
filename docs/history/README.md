# Archived planning and status documents

This folder holds superseded planning, status, and results documents from
earlier phases of the project. They are kept for historical context only;
nothing here is maintained.

Durable task tracking now lives in Todoist (project `Magnus / gausvibe`),
per the policy in the root `AGENTS.md`. If a task described in one of these
files is still relevant, it has been migrated to Todoist.

Contents:

- `bake-off-2.md`, `BAKEOFF_PLAN.md`, `BAKEOFF_EXECUTION.md` - early bakeoff planning
- `BAKEOFF_ES_ROUND4.md` - ES round 4 instruction (executed; results in `etl/results-es4/`)
- `BAKEOFF_ROUND3.md`, `BAKEOFF_ROUND3_RESULTS.md` - round 3 instruction and results
- `CHANGES.md` - historical changelog
- `DEBUGGER_INTEGRATION.md` - JDI differential-debugging design spec (open task in Todoist)
- `EDITING_IMPLEMENTATION_PLAN.md`, `SELF_HOSTING_MVP.md` - self-editing/self-hosting plans
- `ISSUES.md` - known issues at time of archive (open items migrated to Todoist)
- `OPTIMIZATION_SUMMARY.md`, `PERFORMANCE_OPTIMIZATION_PLAN.md` - optimization planning
- `PHASE5_STATUS.md` - phase 5 status report
- `TASK_BREAKDOWN.md` - original implementation breakdown (open items migrated to Todoist)
- `far-fetched-ideas.md` - idea parking lot

Live documentation stays in the repository root: `README.md`, `USAGE.md`,
`RUNBOOK.md`, `GAUSVIBE-SERVER.md`, `QUICK_START.md`, `HOW_TO_EDIT.md`,
`SKILL-SETUP.md`, `CLI_vs_MCP.md`, `TOKEN_ATTRIBUTION.md`, and
`BAKEOFF_ROUND4.md` (active bakeoff instruction).
